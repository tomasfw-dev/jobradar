# RoleGazer

RoleGazer ayuda a centralizar ofertas laborales dispersas en distintos sitios web, evitando la búsqueda manual repetitiva.

## Objetivo

Recopilar ofertas mediante web scraping, procesarlas en segundo plano y mostrarlas en un frontend unificado.

## Stack planificado

- **Backend:** Python, FastAPI, Celery, SQLAlchemy y Alembic
- **Frontend:** React, TypeScript y Vite
- **Infraestructura:** PostgreSQL, Redis y Docker Compose
- **Testing:** Pytest

## Estado

En desarrollo.
